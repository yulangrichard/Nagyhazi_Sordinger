The project is the CSIRO image2biomass Kaggle competition, where the goal is to train a model to be capable of estimating the amount of different biomass in a certain image. 

For now, only the .ipynb file containing the code is uploaded into the repo, as the project goes on, this will be updated and organized. The code is contained within nagyhazi_sordinger_milestone1.ipynb. The data is uploaded in a .zip file on google drive, imported directly through the code.
